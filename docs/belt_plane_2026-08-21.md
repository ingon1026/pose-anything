# 벨트 평면 구속 OBB (2026-08-21)

하방 카메라는 물체 상면만 본다 → 무구속 OBB 는 두께가 붕괴하고 중심이 상면에
얹힌다(08-20 축 분해의 광축 계통 편향 −3.69mm). 벨트 평면을 알면 두 결함이
동시에 풀린다. 구현은 `geometry.obb_on_plane` + `pipeline._fit_support_plane`
(마스크 바깥 링에서 지지면 추정 — 화면 전체로 맞추면 지배 평면이 벨트가 아니라
바닥이라 두께가 569mm 로 나온다, 실측).

## 남은 회귀 1건 — 원인 규명 완료

test4 book: 가림 구간(10.5~20.0s) 발행 105 → 8 프레임. 최대 공백 2.7s → 9.5s.

기각한 가설 2개 (전부 계측으로):
- **규약 폴백/재시드 아님** — 459프레임 중 tilt 폴백 2회, 재시드 3회(=최초 시드뿐)
- **두께 → center z 결합 아님** — 기각 관측의 잔차 축분해에서 z 성분이 −0.6~−4.9mm
  로 사실상 0. 잔차는 전부 면내(x −36→−162mm, y −33→−128mm)
- **두께 과대추정 아님** — 물체 위치에서 잰 (평면 − 상면)이 보고 두께보다 항상 크다
  (bag 157.5/157.0, keyboard 42.7/40.5, book 50.8/43.5). q98 은 보수적이다.
  A 의 두께 26/20/16mm 쪽이 진짜 두께가 아니라 depth 잡음 폭이었다.

**실제 원인**: LK 광학흐름이 가리개(검은 폴더)를 따라가 마스크가 면내로 드리프트
하는 알려진 실패 모드에서, A 와 B 가 정반대로 반응한다.
- A: 관측 잡음이 커 R̂ 이 크고 게이트가 넓다 → 드리프트한 오염 관측을 **수락**
  (d²=6.1). 필터가 따라가지만 5프레임마다 SAM 키프레임이 되돌려 결과적으로
  중앙 13mm 오차로 발행이 유지됐다.
- B: 평면 구속으로 관측이 정밀해져 R̂ 이 하한 근처 → 게이트가 좁다 → 같은
  드리프트를 즉시 **기각**(d²=25.4). 상태가 고정된 채 마스크만 계속 밀려
  잔차가 단조 증가하는 자기 강화에 들어가고, 20.0s SAM 재검출까지 복구 안 됨.

즉 정밀도의 대가다. 근본 처방은 평면 구속 쪽이 아니라 "닮은 depth 가리개에서
LK 드리프트를 끊는 술어"(현행 depth_intrusion 은 폴더가 책과 같은 높이라 안 걸림).

## 결정
- `use_belt_plane` **기본 꺼짐** — `enable_merge`·`pub_score_min` 과 같은 관례
  (한 씬에서만 보정된 값 + 로봇 파지에 직결되는 지표에서 문서화된 회귀)
- 켜는 법: `--belt-plane-on` / ROS `use_belt_plane:=true`, 평면 직접 지정은
  `--belt-plane a,b,c,d`
- 기본 경로 무회귀 확인: test4 기본 실행이 A 와 완전 동일한 수치 재현

### -31% 는 교정이 아니라 회귀다 (오차 분포로 확정)
test4 book, 가림 구간 10~20s, 가림 전 위치 기준 오차:

| | 발행 | 중앙 | p90 | 최대 | >30mm |
|---|---|---|---|---|---|
| A(무구속) | 105프레임 | 13mm | 77mm | 136mm | 27% |
| B(평면) | 8프레임 | 134mm | 134mm | 134mm | 100% |

A 의 73% 가 30mm 이내였다 — "A 의 커버리지는 가짜였고 B 가 쓰레기를 거부했다"는
해석은 **성립하지 않는다**. 게다가 B 가 그 구간에 낸 8프레임은 전부 134mm 틀렸다.
정밀도를 얻고 가용성을 잃은 것이 맞다.

시도하도록 고쳤다. 이후 test3 은 A 와 완전히 동일한 수치로 복귀.

### 링 구성 결함 2건 (test2/test3 에서 발견, 수정됨)
1. 링에 **저점수 검출**(assoc_threshold 0.1)까지 들어갔다 — 오검출 주변은
   물체가 얹힌 면이 아니다. test3 검출 28개로 링 depth 가 0.91~1.73m 로 퍼져
   인라이어 0.14. → 고점수(detector.threshold)만 사용
2. 링에 물체 상면·배경이 섞여 인라이어 비율이 의미를 잃었다. test2 는 평면이
   맞았는데도 0.28 로 문턱 아래 탈락. → depth 중앙값 ±50mm 밴드 클립 후 RANSAC
   (test2 0.42 / test4 0.41 통과, test3 0.27 탈락 — 의도한 동작)
