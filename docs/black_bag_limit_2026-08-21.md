# black bag 오염 발행은 센서 한계다 (2026-08-21)

풋프린트 게이트를 넣은 뒤에도 test4 black bag 만 30mm 초과 발행이 **41%** 로
남았다(다른 물체는 0~5%). 원인을 규명했고 **코드로 고칠 수 없다는 결론**이다.

## 지표부터 검증했다
"정지 씬 가정으로 초반 8s 중앙값을 기준으로 썼는데 가방이 실제로 움직였으면
지표가 무의미하다" 는 의심을 먼저 확인했다. 세 독립 기준이 일치한다:

| 기준 | >30mm |
|---|---|
| 초반 8s 중앙 | 41% |
| 전체 중앙 | 36% |
| raw 최청정 10% 중앙 | 43% |

가방은 움직이지 않았다(x 가 −427 → −436mm 로 복귀). **41% 는 실재한다.**

## 원인: depth 결측과 오차가 완전 단조

점 개수 5분위별 raw 중심 오차(test4):

| 점 개수 | 중심 오차 | >30mm |
|---|---|---|
| 8000~9999 | 18mm | 33% |
| 6000~8000 | 70mm | 100% |
| 4000~6000 | 106mm | 93% |
| 2000~4000 | 141mm | 96% |
| 0~2000 | 190mm | 100% |

전체 프레임의 **28% 가 중앙값의 절반 미만 점**을 갖는다. 검은 무광 표면이
depth 를 흡수한다. 장축도 같이 무너진다(564 → 366mm).

## 필터는 제 일을 하고 있다

물체별 raw 관측 품질:

| | 프레임간 \|Δ\| | 축별 \|중앙편차\| |
|---|---|---|
| black bag | 17.6mm | [21, 45, 8]mm |
| book | 3.1mm | [0.8, 0.9, 1.3]mm |
| keyboard | 2.0mm | [1.1, 1.0, 0.5]mm |

book·keyboard 는 관측의 절반 이상이 1mm 이내고 std 는 소수 이상점이 만든다.
black bag 은 **분포 자체가 퍼져 있다.** 필터는 raw 17.6mm/frame 을 발행
2.7mm 로 6.5배 평활한다 — 알고리즘 층은 이미 할 수 있는 것을 하고 있다.

**가장 깨끗한 프레임(pts 8000+)조차 중앙 18mm, 33% 가 30mm 를 넘는다.**
근본 원인이 센서 단이라 게이트로 남는 여지가 없다. 낮출 방법이 있다면
조명·노출·재질 쪽이지 코드가 아니다.

## 시도했다가 되돌린 것: 게이트 측정량을 면적 → 점 개수로

면적은 *바깥 상자*라 표면에 구멍이 뚫려도 잘 안 변한다. 측정량으로서 점
개수가 더 맞다는 가설을 raw 시뮬레이션으로 확인했고(검출률 black bag
40.9→49.4%, book 80.3→95.5%, keyboard 94.6→97.3%), 실제로 구현해 회귀를
돌렸다. **결과가 예측과 달랐다:**

| | 면적(현행) | 점 개수 |
|---|---|---|
| test4 black bag | 41% (p90 87) | **49%** (p90 103) |
| test4 keyboard | 0% | 0% |
| test4 book | 1% (p90 11) | 1% (p90 6) |
| test5 black bag | 47% | 44% |
| test5 keyboard | 23% (p90 98) | 20% (p90 80) |
| test5 book / notebook | 3% / 5% | 3% / 5% |

이득이 뒤섞이고 test4 black bag 은 오히려 악화한다. 순이득이 없어 **되돌렸다**
(현행은 면적 유지). raw 시뮬레이션이 실기 회귀를 대신하지 못한다는 사례가
하나 더 늘었다.

## 곁가지 함정
`num_points` 의 뜻이 경로마다 다르다 — `compute_obb` 는 5mm voxel 다운샘플
후라 거리에 무관하고, `obb_on_plane` 은 raw 라 거리에 의존한다. 점 개수를
쓰는 판정을 다시 시도한다면 이 차이를 먼저 처리할 것.

## 결론
- **black bag 41% 는 수용한다.** 이 물체는 D455 로는 이 이상 안 된다
- 개선하려면 하드웨어·촬영 조건(조명·노출·편광, 또는 표면 처리)
- 게이트가 74% → 41% 로 절반 가까이 줄인 것은 그대로 이득이다
