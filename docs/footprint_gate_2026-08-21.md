# 부분 가림(풋프린트 절단) 게이트 — 기본 꺼짐 (2026-08-21)

## 문제
test4 book 10~20s 에서 가림 중 **최대 137mm 오차**로 좌표가 발행되고 있었다
(30mm 초과 프레임이 30%). 파지 목표 ±10mm 기준 명백한 결함이고 기본 경로의
문제였다.

같은 날 두 가설을 실측으로 기각했다:
- **"LK 가 마스크를 가리개 위로 미끄러뜨린다"** — 아니었다. 흐름 일관성
  게이트(`FLOW_INLIER_*`)를 넣어도 27% -> 30% 로 무개선
- **운동 일관성 / 외형(색) 채널** — 오염 구간을 분리하지 못한다

실제로 일어난 일: **가리개가 물체를 조금씩 덮어 보이는 영역이 줄고, 그 줄어든
영역의 중심이 밀린 것**이다. 오차와 면적이 한 몸으로 움직인다(오차 14->95mm
동안 면적비 1.15->0.754). 마스크는 끝까지 물체 위에 있었다.

즉 **부분 가림은 화면 절단(`_touches_border`)과 같은 종류의 사건**이다 —
보이는 부분의 중심은 물체의 중심이 아니다. 화면 경계 쪽은 이미 처리하고
있었는데 가리개 쪽은 아무도 안 보고 있었다.

필터의 extent 로는 구조적으로 못 잡는다: 프레임당 변화가 3mm 라 χ² 를 매번
통과하고, 통과할 때마다 extent 상태가 따라 내려가 다음 프레임의 기준이 된다
(천 번의 작은 베임). 그래서 **드리프트보다 훨씬 느린 기준**(log 미터 면적,
EMA α=0.02)을 따로 두고, 이탈하면 관측을 통째로 버린다.

## 목표는 달성했다
```
test4 book 10~20s     발행    중앙     최대    >30mm
  게이트 없음         108    14mm    137mm     30%
  게이트 TAU=0.14      77     4mm     25mm      0%
```

## 그런데 물체 형상에 따라 갈린다 (발행 / p90mm / >30mm%)

| 물체 | 없음 | TAU 0.14 | 0.20 | 0.28 |
|---|---|---|---|---|
| **book** (test4) | 355 / 68 / 17% | 239 / **9** / **0%** | 243 / 19 / 3% | 284 / 14 / 4% |
| **book** (test5) | 711 / 68 / 13% | 357 / **3** / **2%** | 386 / 3 / 3% | 463 / 4 / 5% |
| **gray notebook** | 821 / 44 / 19% | 650 / **19** / **5%** | 700 / 21 / 6% | 699 / 22 / 5% |
| **black bag** (test4) | 300 / 127 / 74% | 110 / 132 / 62% | 138 / 135 / 70% | 149 / 145 / 72% |
| **black bag** (test5) | 614 / 118 / 51% | 352 / 67 / **28%** | 312 / 68 / 50% | 405 / 76 / 54% |
| **keyboard** (test4) | 239 / **2** / **4%** | 93 / 89 / 39% | 90 / 60 / 28% | 141 / 89 / 22% |
| **keyboard** (test5) | 377 / 59 / 26% | 254 / 112 / 31% | 267 / 98 / 29% | 267 / 48 / 18% |

- **뭉툭한 물체(book·notebook)**: 확실한 이득. 오염 발행이 사실상 사라진다
- **세장 물체(keyboard, 402x126mm)**: **어느 문턱에서도 악화.** test4 는 원래
  p90 2mm / 4% 로 거의 완벽했는데 22~39% 가 된다. 면적 하나로 보므로 세장
  물체는 한 축만 잘려도 면적이 크게 변하는 것이 원인으로 보인다(**미확인**)
- **무텍스처(black bag)**: 일관성 없음. test5 에서만 이득(51%->28%), test4 는
  거의 무이득인데 발행만 반토막

**전 물체를 만족시키는 TAU 가 없다.** 그래서 기본은 끈다 —
`enable_merge`·`use_belt_plane` 과 같은 관례다.

## 켜는 법
`--footprint-gate` / ROS `enable_footprint_gate:=true`

씬의 물체가 뭉툭하고 가림이 잦으면 켠다. 세장 물체가 있으면 위 표의
keyboard 행을 보고 판단할 것. 켠 뒤에는 `scripts/check_accuracy.py` 로
기준 대비 회귀를 확인할 것.

기준 EMA 는 게이트가 꺼져 있어도 매 프레임 돈다 — 켜는 순간부터 기준이
유효하려면 항상 따라가고 있어야 하고, 부작용이 없다.

## 설계에서 실측이 예상을 뒤집은 것 두 가지
- **r_extra 로 흡수하면 안 된다.** 불확실성을 키우면 게이트가 함께 넓어져
  오염 관측이 *더 잘* 수락된다(합성 회귀에서 500mm 침입이 통과). 원하는 건
  "덜 믿는다" 가 아니라 "이 프레임은 안 본다" 다
- **기준 동결 + 채택 상계는 못 쓴다.** 매끄러운 드리프트는 언제나 자기들끼리
  일관해서 그 탈출구로 걸어 들어온다(검출 72% -> 14% 붕괴). 그냥 EMA 로
  따라가게 두면 검출은 같고 오탐은 더 낮으며(17.8% -> 7.2%), 교착이
  **구조적으로** 불가능해진다 — 편차 D 는 기하급수로 닫혀
  `ln(TAU/D)/ln(1-α)` 프레임 안에 반드시 풀린다

## 못 잡는 것
- **회복 국면** — 필터가 이미 틀린 상태에 수렴해 있으면 걸어 돌아오는 데
  2.5초 걸린다. 이 게이트는 그 상태에 *들어가는 것*만 막는다. 필터 발산
  감지(부호 일관 혁신 런)가 별건으로 남는다
- 가리개가 물체와 비슷한 크기로 정확히 갈아타는 경우 (면적 불변)
- 한 축이 줄고 다른 축이 늘어 면적이 상쇄되는 가림
- 트랙이 처음부터 오염된 마스크로 시드된 경우 (그 크기가 기준이 된다)

## 미해결
- keyboard 악화의 원인이 "세장 형상 + 면적 스칼라" 가설로 설명되는지 미검증.
  축별로 보면(장축/단축 따로) 해결될 수 있으나 안 해봤다
- 상수 TAU·ALPHA 는 test4 book 한 사례의 고원값이다. 위 표가 bag 2개
  7물체로 넓혔지만 라벨된 오염 구간이 있는 것은 여전히 test4 book 뿐이다
